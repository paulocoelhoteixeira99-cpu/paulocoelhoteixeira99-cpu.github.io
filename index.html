What I Built

Database Architecture

Designed a PostgreSQL schema with 30+ tables covering the full lifecycle: raw leads, processed leads, SMS dispatches, click tracking, VSL events, cart abandonment, sales, opt-outs, and spam monitoring.

Lead Scoring Engine

Built a dynamic scoring algorithm (0-100 pts) combining static origin data with real-time behavioral signals. Implemented via a central PostgreSQL function called by 6 automated triggers, processing 689K+ score-change events with full audit trail.

Real-Time Event Pipeline

Engineered a tracking system that captures every user interaction: SMS delivery, link clicks, VSL engagement (play, midpoint, pitch view), checkout initiation, and purchase. Each event updates lead score and group assignment in real time.

Automated Campaign System

Built n8n workflows for automated SMS campaigns segmented by funnel stage (G0-G4). Includes daily dispatch rules, frequency capping, opt-out compliance (TCPA), and A/B copy rotation. 5 active campaign groups running simultaneously.

AI Voice Agent Integration

Integrated a VAPI-powered AI voice agent for real-time call recovery of high-intent leads. The system triggers calls within 10 minutes of checkout abandonment, with 3,724 calls executed to 449 unique leads.

Analytics Dashboard

Created Metabase dashboards with 11+ cards tracking funnel performance, lead score distribution, group velocity, conversion rates, frozen/blacklist monitoring, and daily dispatch volume.
